# 第三方组件与标识

**[Powered by MinerU](https://github.com/opendatalab/MinerU)**

SolidCog 使用 MinerU 提供本地文档解析能力，包括文字、表格与布局提取。

## 分发与服务部署

分发 SolidCog，或部署给客户及其他第三方提供服务时，须保留以下位置的 `Powered by MinerU` 标识：

- 项目 README 与本文档。
- 工作台页脚及其「关于 SolidCog」入口。
- `/about` 关于页中的文档解析支持标识。

定制界面或部署包时，也须保留用户可访问的标识展示。部署更新后，检查 `/home` 和 `/about` 是否正常显示上述文字与 MinerU 项目链接。

## 许可证边界

MinerU、MechVL、Qwen 及其他第三方组件分别适用其自身许可证或服务条款，模型权重适用对应模型的许可。SolidCog 自有代码的 Apache License 2.0 不替代这些许可。标识不替代第三方许可中的其他义务；部署和分发时应核对实际使用版本附带的许可文本。
