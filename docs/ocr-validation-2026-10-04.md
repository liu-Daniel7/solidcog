# 机械图纸 OCR 改进与验证（2026-10-04）

本次使用三个用户指定的 6-luna 子代理分别处理 Qwen 多视图、MinerU 分区和全链路审查，主代理整合 macOS 本地识别与文件输入。

## 实现

- 保留整页上下文，同时逐块读取高分辨率重叠区域，覆盖图纸边缘。
- macOS MinerU 将被布局模型分类为图片的机械视图再次按文字抽取，保留尺寸、公差、文字与原始坐标；PDF 默认 300 DPI。
- 标题栏以字段组合识别，不再依赖固定右下角；技术要求支持冒号、普通文本标题、多页和缩进说明；结构化结果可补偿缺失 Markdown。
- 多页 TIFF、JPEG、BMP、WebP 可上传；PNG 透明背景白底合成，栅格图读取 EXIF 方向。
- 区域失败和页数限制明确显示，全文不再被存储层静默截断；不同位置的相同尺寸保留。

## 验证边界

自动化测试覆盖边缘分块、重复尺寸、局部失败、全空结果、JSON 边界、多页分区、标题栏位置、透明背景、多页 TIFF 和页数截断提示。Qwen 调用使用 mock，未执行收费的云端准确率评测。

一张图纸不足以证明跨图纸泛化。模糊、旋转、遮挡、手写、非标准符号和非标准布局仍需带人工标注的样本验证。DWG/DXF 应先导出 PDF/图片。高分辨率分块增加本地耗时与云端调用费用。
