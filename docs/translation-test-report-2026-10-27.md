# SolidCog 翻译功能测试报告

测试日期：2026-10-27

测试对象：《新标准机械图图集 王静编著》中的 10 张代表性图纸

测试模型：Qwen-VL（云端 OCR）＋ Qwen-MT Plus（翻译）
测试方式：真实 API Key，真实图纸，仅发送 OCR 提取文字，不上传翻译阶段的图纸图片。

## 结论

本轮 10 张图的翻译链路全部跑通：

- 84 条文本条目
- 66 条实际翻译
- 18 条代码/材料/图号等无需翻译
- 0 条失败
- 0 条待复核
- 0 条缺失
- 81 个受保护的工程数据 token 全部原样保留

结论：**功能可用，适合做客户演示和工程辅助翻译；当前不应直接作为正式交付译文。** 主要剩余问题是 OCR 杂讯偶尔混入技术要求，以及术语大小写/句式还不够统一，需要人工复核和客户术语库调优。

## 工程数据保持

对源文和译文逐条比对，以下数据均未发生改写、单位换算或标准替换：

- 尺寸：`0.02mm`、`0.1～0.15mm`、`R3～R5`、`C0.5～C1`
- 硬度：`40～50HRC`、`240～290HBW`、`20～24HRC`
- 标准：`GB/T 1804—2000—m`、`GB/T 1184—1996—K`、`GB/T 9441—2009`
- 材料：`45`、`QT600`、`HT200`、`HT150`
- 图号：`LJT03.16`、`LJT03.22`、`LJT05.24`、`ZPT06`、`ZPT31`

其中材料、图号、纯数字等 18 条按规则标记为无需翻译，直接保留原文。

## 翻译质量观察

### 表现较好的部分

- 标题栏字段基本稳定：图名、图号、材料可逐条对应；
- 技术要求按编号拆分，未出现串行、漏项或译文错位；
- 硬度、公差、标准号、材料牌号全部保持；
- 装配图能识别图名和图号，BOM 行没有污染标题栏；
- CSV 导出保持原文和译文位置对应。

### 需要修的问题

1. **OCR 杂讯混入技术要求（中等）**
   - 第 60 页第 7 条末尾混入了 `淬火硬度38~43HRC 莫氏锥度4# Ra1.6`；
   - 第 168 页第 6 条末尾混入了重复的技术要求碎片；
   - 第 230 页第 2 条末尾混入了 `≤356`。
   这些内容被翻译进译文，虽然不影响字段对应，但会增加人工复核成本。

2. **术语大小写和句式不统一（中等）**
   - 例如 `The Casting shall be free from Defects...`
   - `Unspecified dimensions Tolerance per...`
   - `during Assembly`
   术语表中的名词被模型按首字母大写使用，建议后续将普通名词术语改为小写，并给常见句式增加参考译文。

3. **部分术语需要客户确认（中等）**
   - `滑柱` 译为 `Slide post`
   - `读数盘` 译为 `Reading dial`
   - `轴座` 译为 `Shaft seat`
   这些译法可理解，但不同客户可能有自己的标准叫法，应通过客户术语库覆盖。

4. **批量快速请求会触发 429（低）**
   - 连续翻译 10 张图时，最后两张首次请求遇到 Qwen-MT 速率限制；
   - 冷却 60 秒后强制重试，两张均成功；
   - 当前 3 路并发对连续批量仍偏激进，建议批量翻译时降为 1–2 路并增加更长退避。

## 建议下一步

1. 对第 60、168、230 页的 OCR 尾部杂讯做清洗规则；
2. 将术语库普通名词统一为小写，补充“未注尺寸公差”“未注几何公差”等完整句式；
3. 批量翻译默认并发降为 1–2，遇到 429 使用更长指数退避；
4. 再选 20–30 张图，由机械工程师按“术语、漏译、错译、数据保持”四项抽检；
5. 通过客户样本建立客户级术语库后，再对外承诺正式交付质量。
